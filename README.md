## 🚀 About The Project

This project is a colorful geometric layout created using **HTML5 and CSS Grid**.

It features multiple rectangular blocks arranged in a structured grid, demonstrating how CSS Grid can be used to create modern layouts with different sizes and positions.

The project focuses on grid containers, columns, rows, spacing, and individual item placement.

## ✨ Features

- 🎨 Colorful geometric design
- 📐 CSS Grid-based layout
- 🔲 Multiple rows and columns
- 🧩 Custom grid item positioning
- ↔️ Column spanning and row spanning
- 🎯 Clean HTML structure
- ⚡ Lightweight and fast

## 🛠️ Built With

| Technology | Purpose |
|---|---|
| HTML5 | Structure and layout elements |
| CSS3 | Styling and visual design |
| CSS Grid | Grid-based positioning |

## 📚 What I Learned

- `display: grid`
- `grid-template-columns`
- `grid-template-rows`
- `grid-column`
- `grid-row`
- `gap`
- Grid item positioning
- Creating layouts using grid lines

The goal of this project was to strengthen my understanding of CSS Grid and practice creating structured layouts using grid-based positioning.

Instead of manually positioning every element, CSS Grid allows me to control the layout through rows, columns, and grid lines.
